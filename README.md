# Sistema de Biblioteca

## Objetivo
Desenvolver um sistema de cadastro de livros para praticar
programação e o uso do Git e GitHub.

## Funcionalidades
- Cadastrar livros.
- Listar os livros cadastrados.

## Tecnologias
- Java
- Git
- GitHub

## Como executar
O projeto será desenvolvido em Java.
As instruções de execução serão adicionadas conforme
as funcionalidades forem implementadas.
